# 블록(Block)

![블록](images/display-summary-001.png)

위에서 아래로 차례대로 배치되는 요소입니다. 크기를 지정할 수 있습니다.

다음 태그들은 기본적으로 `display` 값이 `block`입니다.

- h1,h2,,,h6
- div
- p

---

# 인라인(Inline)

![블록](images/display-summary-002.png)

글을 쓰는 방향으로 줄이 바뀌면서 배치됩니다. 블록과 달리 크기를 지정할 수 없습니다.

다음 태그들은 기본적으로 `display` 값이 `inline`입니다.

- a
- br
- img
- span

참고로 이미지 같이 외부 데이터를 보여 주는 태그는 인라인이지만 크기를 지정할 수 있습니다.

---

# 인라인 블록 (Inline-block)

![블록](images/display-summary-003.png)

인라인처럼 배치되지만 블록처럼 크기를 가지고 싶을 때 사용하는 `display` 속성입니다.

---

# float 속성

![블록](images/display-summary-004.png)

`float` 속성은 요소를 페이지 왼쪽이나 오른쪽에 삽화처럼 배치하고, 그 주변으로 인라인 요소들을 배치할 수 있습니다.

---

# 블록, 인라인 블록, 인라인 비교

|                   | 블록          | 인라인 블록      | 인라인                                       |
| ----------------- | ------------- | ---------------- | -------------------------------------------- |
| 기본 크기         | 좌우로 꽉 참  | 콘텐트에 딱 맞게 | 콘텐트에 딱 맞게                             |
| 배치              | 위에서 아래로 | 글 쓰는 방향     | 글 쓰는 방향                                 |
| width 와 height   | O             | O                | X                                            |
| margin 과 padding | O             | O                | br인라인 진행 방향(=가로)만 제대로 사용 가능 |
